# Python-MIP Analysis

## Method
Mixed Integer Linear Programming (MILP)

## Problem Type
Used simplified linear approximation:

max 3x + 2y
subject to linear constraints

## Strengths
- Exact integer optimization
- Fast for small linear problems
- Reliable solver performance

## Limitations
- Not suitable for nonlinear traffic models
- Requires linearization of BPR (loss of realism)

## Results
- Correct optimal integer solutions
- Efficient computation
- Not applicable to full traffic equilibrium without approximation
