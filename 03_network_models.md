# Network Models

## 1. Braess Paradox Network
- 4 nodes, 5–6 links
- Demonstrates counterintuitive congestion effects
- Used for correctness validation

## 2. Grid Network
- NxN structure (3x3, 5x5, 10x10)
- High path redundancy
- Tests scalability and computational load

## 3. Chain Network
- Linear topology
- Used for runtime scaling analysis

## 4. Sioux Falls Network
- 24 nodes, 76 links
- Real-world benchmark dataset
- Standard in traffic assignment research

## Purpose
These networks evaluate:
- numerical stability
- scalability
- realism
- solver robustness
