# Pyomo Analysis

## Method
Algebraic modeling framework using external solvers

## Solver Used
- IPOPT (nonlinear optimization)

## Strengths
- Highly expressive modeling language
- Suitable for large structured problems
- Industry-grade formulation style

## Limitations
- Requires external solver installation
- Solver availability issues in environment
- Slower setup compared to CVXPY

## Results
- Correct formulation achieved
- Solver dependency limited execution in this setup
- Best suited for production-scale optimization systems
